# Deep in Dungeon Coop — strona prototypu

Statyczna strona osobnego projektu kooperacji. Pliki w `gra/` muszą pochodzić
z nowego eksportu Web bieżącego projektu Godot, nie z historycznego builda solo.

Etap 2: lobby, wspólna mapa, ruch postaci i lokalny zapis hosta. Walka, łupy,
interakcje i kolejne piętra coopa pozostają etapem 3. Biblioteka i historia
gry bazowej 0.40 są zachowane jako osobno opisane materiały.

Sekcja Zagraj udostępnia Web oraz testowy APK coopa na Androida ARM64:
https://github.com/owca217/deep-in-dungeon-site-coop/releases/download/coop-etap2-android-1/DeepInDungeon-Coop-Etap2-arm64.apk
Zapis coopa przechowuje lokalnie host; jest odrębny od solo i przeglądarki.
Testu na fizycznym telefonie nie zadeklarowano. Metadane wydania (rozmiar,
SHA256 i minimum Androida) w data/content.js uzupełnia się z gotowego APK.

Repozytorium: https://github.com/owca217/deep-in-dungeon-site-coop
